# Pull Request Workflow

## Workflow Process

1. Create a new feature branch
2. Push changes to GitHub
3. Open a Pull Request to main
4. GitHub Actions automatically runs tests
5. If tests pass:
   - PR can be reviewed
   - PR can be merged
6. If tests fail:
   - Merge is blocked

---

## Benefits

- Prevents unstable code from reaching production
- Ensures testing consistency
- Improves collaboration
- Supports continuous integration practices
