# Contribution Strategy

## Step 1
Review CONTRIBUTING.md guidelines before making changes.

## Step 2
Comment on issues before starting work to avoid overlap.

Example:
"I would like to work on this issue."

## Step 3
Create feature branches for each fix.

Example:

```bash
git checkout -b fix-validation

## Step 4

Keep pull requests small and focused.

## Step 5

Run tests and ensure CI/CD checks pass before submitting PRs.

## Step 6

Respond quickly to feedback and requested changes.
